About A* Search

A* is an informed search algorithm that finds an optimal path using both the actual cost and estimated distance.

f(n) = g(n) + h(n)

g(n): Cost from start to current cell.

h(n): Manhattan distance from current cell to goal.

f(n): Estimated total path cost.
